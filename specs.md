# Knit&Crochet

idea general, crear una aplicacion web con persistencia en base de datos directa usando next.
para poder guardar projectos de tejidos/crochet, guarda info de lanas, guardar patrones, tener estadisticas, cronometro por projecto y calculadoras de utilidad.

## Paginas:

### Principal
metricas de cuanto se tejio en el año (usar compartivas para hacerlo ma gracioso) filtro por años. horas de tejido. y filtrados para la mestricas.
la idea es que sea un tipo dashboard pero sin ser algo a nivel contable.
dos botones que permitan crear projecto de tejido a dos agujas o a crochet
lista de proyectos activos

### proyectos
filtros(varios, principales activo/noactivo estos por aparte)
botones para cambiar el tipo de projetco en vista dos agujas/crochet
crud de proyectos
listas de proyectos: cada item deben tener foto nombre y barra de progreso y tiempo total llevado hasta ese momento
al tocar cada item se debe desplegar un menu para ver o modifcar el proyecto, segun las necesidades y la mutabilidad del objeto
botones para el crud.

### Lanas
filtros: se va a dividir en marca y luego las marcas se dividen en tipo.
crud de lanas
lista de lanas totales: cada item debe tener un icono general marca -  tipo color y cantidad(stock)
botones para el crud

### Patrones 
filtros(varios, principales activo/noactivo estos por aparte)
botones para cambiar el tipo de patron en vista dos agujas/crochet
crud de proyectos
listas de patrones: cada item deben tener foto nombre 
botones para el crud.

### Stash 6 tools:
pagina con una lista que enlaza a cada funcionalidad de la app (calcualdoras, poryectos, patrones, etc)
